# LotoLab 4.26.13

- Corrige o botão de salvamento do Fechamento Lotofácil 4-3-3-2-3.
- Grava os jogos em **Meus jogos**, mostra confirmação e abre a lista após salvar.
- Se o aparelho recusar a gravação, o aplicativo informa o erro e não declara sucesso.
- Mantém a carteira e o acompanhamento do laboratório quando a gravação de metadados é possível.

A correção não altera as probabilidades matemáticas dos sorteios.

A atualização Android usa o mesmo identificador do aplicativo, versionCode 50 e a assinatura permanente verificada. Instale o APK regular por cima da versão anterior para manter os dados do aplicativo.
