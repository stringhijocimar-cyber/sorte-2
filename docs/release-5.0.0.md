# LotoLab 5.0.0

- Em **Meus Jogos**, abra uma cartela para ver o diagnóstico abaixo do volante. A faixa central usa os percentis 10 e 90 de pelo menos 30 concursos comparáveis. A cor verde indica que a soma está dentro dessa referência histórica.
- **Últimas conferências** e **Resultados** mostram, por concurso, as apostas em faixa, o prêmio calculado pelo rateio da CAIXA, o gasto informado e o saldo. Para registrar o custo, abra a cartela e use **Registrar aposta paga**.
- Jogos de acompanhamento aparecem separados. Valores sem informação ficam indisponíveis. Na Timemania e no Dia de Sorte, preencha o complemento da cartela conforme o bilhete.
- Em **Sugestões → Lotofácil**, o fechamento 4-3-3-2-3 gera 32 jogos e permite salvá-los para conferência. A avaliação usa 32 carteiras aleatórias de igual custo por concurso, sem usar o resultado avaliado para gerar os jogos.

Android usa o identificador `app.lotolab.jogos` e o código 53. A instalação sobre a 4.26.15 depende de o APK usar o mesmo certificado permanente.
